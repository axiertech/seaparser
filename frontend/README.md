# Frontendbas

Ingen UI eller visuell editor finns ännu. package-lock.json låser den tomma
beroendegrafen. node_modules är lokal och ignorerad. `npm run check` kontrollerar
syntax; `npm test` hittar för närvarande inga produkttester. Lägg till tester
med första komponenten. React/TypeScript/editor måste utvärderas separat.
